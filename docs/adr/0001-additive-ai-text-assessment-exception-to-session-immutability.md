# Additive exception to session-data immutability for KI-Einschätzung

Session data is immutable once approved. The KI-Einschätzung effort (Wayfinder-Karte [#501](https://github.com/JensWinter/StadtratWatch-web/issues/501)) needs to retroactively add or overwrite an optional `aiTextAssessment` field on already-approved `session-speeches-*.json` files — to catch up 2026 sessions processed before the feature existed, and to re-score a speech whose `aiTextAssessment.transcriptSha256` no longer matches its (corrected) transcript. We decided this is allowed as a narrow, permanent exception: the write must (1) touch only the single `aiTextAssessment` field — either adding it where absent or overwriting its entire value where already present, and never touch any other field, (2) come exclusively from a run of the `detect-ai-text` script, never a manual edit, and (3) land in its own commit referencing the originating Wayfinder ticket. The script overwrites, it does not keep a history of prior values — the previous value remains recoverable from git history if ever needed. Any other retroactive change still falls under the general immutability rule.
