# Coding Standards

Rules the reviewer applies to a diff. Conventions in `AGENTS.md` (Code Conventions, Boundaries) apply as well.

## Documentation

- **Removals delete their mentions.** When a change removes a file, folder or step, delete every mention of it from the docs. Record where it now lives in exactly one place: the arc42 concept or diagram that already shows that flow. Notes that only explain an absence ("X is not in `data/`", "do not commit X") are findings.
